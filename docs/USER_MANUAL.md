# User Manual

## Logging In

Users must authenticate using the standard login page. Verified email addresses are required for protected modules.

## Dashboard

The dashboard provides:

- complaint metrics
- SLA performance
- branch and product analytics
- recent complaint activity

Live filters allow users to narrow data by branch, product, status, category, and date range.

## Complaints

Users with access can:

- submit complaints
- view complaint details
- assign and close complaints
- reopen complaints when authorized

## Feedback

Users can submit and manage feedback entries.

## Public Tracking Portal

Customers can track complaints using the complaint reference number.

- complaint history is visible
- satisfaction surveys are available after resolution
- public reopen is available for eligible tickets

## Notifications

In-app notifications show recent updates and unread counts. Users can mark notifications as read individually or all at once.
