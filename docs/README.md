# GLEDCO Feedback Management System Documentation

This folder contains the system overview, operating guides, and checklists for the GLEDCO Feedback Management System. Start with `SYSTEM_ARCHITECTURE.md` for a whole-system explanation, data concepts, and Mermaid flowcharts.

- `INSTALLATION_GUIDE.md` - local and shared environment setup.
- `DEPLOYMENT_GUIDE.md` - Hostinger and production deployment instructions.
- `ADMINISTRATOR_GUIDE.md` - system administration, access, and permissions.
- `USER_MANUAL.md` - feature walkthrough for end users.
- `MAINTENANCE_GUIDE.md` - ongoing maintenance tasks and backups.
- `TROUBLESHOOTING_GUIDE.md` - common issues and fixes.
- `UAT_CHECKLIST.md` - user acceptance testing scenarios.
- `PRODUCTION_READINESS_CHECKLIST.md` - final release checklist.
- `SYSTEM_ARCHITECTURE.md` - whole-system documentation, modules, data relationships, route map, operations, and flowcharts.
